Sunset Bay — an original open-world crime game in static files. Explore a sun-soaked coastal city on foot and by car, with traffic and pedestrians, stealable cars, a wanted level with police chases, five story missions, combat, a HUD with minimap, and synthesised sound. Built with Three.js; no network request, no build step.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Keyboard and mouse: WASD to move and drive, E to steal or exit a car, F or click to punch, Shift to run, Esc to pause, M to mute.
